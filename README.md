# CSVHub 数据工作台

通用 CSV / Excel 数据工作台，适用于有权处理的业务数据和合成数据。Python 3.12+、FastAPI、SQLite，包含中文网页前端，没有连接或导入任何外部住客文件。

## 已实现

- 所有已导入字段均可作为查询条件，兼容未建立索引的字段；保留索引查询、组合条件、游标分页、超时与缓存。未索引的大数据查询可能较慢。

- XLS / XLSX 上传、工作表选择与预览、类型转换、后台导入和索引查询；[Excel 操作与容量说明](EXCEL.md)。

- 分块流式上传，默认 8MiB/块、20GiB/文件；块 SHA256 和整文件 SHA256 验证。
- 上传断点恢复：查询 `received` 后从该位置继续；重复提交旧偏移会返回 409。
- UTF-8 / UTF-8 BOM / GB18030，标准 CSV 引号、逗号和字段内换行。
- 可配置列映射，text/integer/date 类型，前导零保留，可选去空格、空值规则。
- 单独的导入进程、持久化任务、暂停/恢复/取消、低磁盘空间暂停。
- 数据和检查点同一事务提交；进程重启重新扫描到已提交记录，随后续写。
- 首次全量写入后建索引，完整性检查，准备首屏缓存，然后原子发布版本。
- 精确、前缀、范围和组合条件查询；游标分页、参数绑定、查询超时、并发上限。
- 128MiB 预算的 LRU 结果缓存；缓存与游标绑定数据版本。
- 默认首屏结果在导入过程中持久化预热，API 首次使用时载入自身缓存。
- 管理员 / 普通用户账号、密码登录、服务端权限校验；普通用户仅能使用概览、提取和查询。
- 100～1000 条顺序提取、历史批次、独立标注与备注；[账号和提取操作说明](ACCOUNTS-EXTRACTION.md)。
- 保留原管理员令牌、简要操作审计、OpenAPI 文档。
- 标注与备注持久保存到 SQLite，在查询结果末尾显示当前账号的状态与备注；查询缓存命中时仍读取最新标注。

## 安装和运行

0.3.10 起，Windows 新机器先双击 `install.cmd`，安装成功后双击 `start.cmd`。首次安装需要联网，适用于 64 位 Windows 10 / Windows Server 2016 及更新系统。请将 ZIP 完整解压到可写目录后运行，不能直接在压缩包内启动。详细步骤与失败处理见 [安装说明](INSTALL.md)。

安装脚本自动检测可用的 64 位 Python 3.12+；缺少时从 Python 官网下载 Python 3.13.16，校验 SHA-256 和发布者签名后为当前 Windows 用户安装，并配置该用户的 Python PATH。随后创建项目 `.venv`、安装全部运行依赖、生成 `.env` 默认配置、准备数据目录和首次管理员令牌，并检查依赖、SQLite 与后端导入。前端由后端直接提供，SQLite 随 Python 提供，无需另装 Node、数据库服务器或编译工具。重复安装会保留 `.env`、数据库、账号与令牌；更新安装前先用 `stop.cmd` 停止服务。

根目录只有一个安装脚本和三个服务脚本，三个服务入口均管理当前项目与数据目录的网页服务和导入执行器：

| 脚本 | 操作 |
|---|---|
| `install.cmd` | 自动安装与检查运行环境，保留已有配置及业务数据 |
| `start.cmd` | 启动两个服务，已运行时复用，确认可用后打开首页 |
| `restart.cmd` | 停止现有两个服务，再按当前配置启动 |
| `stop.cmd` | 停止两个服务，保留数据库、上传文件及已提交导入进度 |

三个脚本从任意目录执行都会定位自身项目目录，不区分本机、局域网或 VMware 访问。默认监听所有 IPv4 网卡的 8000 端口，不依赖具体服务器 IP。升级后第一次使用 `restart.cmd` 载入更新，之后按需要使用启动或停止脚本。服务管理依赖 psutil，已纳入普通运行依赖。

控制器按项目目录、数据目录、服务模块和记录进程的创建时间核对归属，并可找回直接以 `python -m csvhub.api` / `python -m csvhub.worker` 启动或未完成登记的服务。变更 Python 环境后仍能管理原环境启动的对应服务。重复点击操作通过同一个控制锁协调；服务尚未完全停止时不会重复启动。停止时执行器优先在已有检查点处退出，旧版本执行器也可停止；重新启动后按已提交进度恢复。
服务在后台运行，日志保存在 `data/logs`。复制到其他电脑时运行 `install.cmd`，它会重建无效的旧虚拟环境，并将旧目录保留为 `.venv.backup-*`。
这是在普通桌面环境运行的入口；受限工具会话中的服务可能无法被桌面浏览器访问。

也可在本目录使用 Python 3.12 或更新版本手动安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .
.\start.cmd
```

启动脚本优先使用项目虚拟环境；在当前开发环境可使用已准备的 Codex Python 与工作目录依赖，也支持系统 PATH 中的 Python 或 Windows 的 py 启动器。启动前会检查 Python 版本和运行依赖。安装器只安装运行依赖；需要测试工具时额外安装 `.[test]`。

Linux 服务器可使用 `python3 -m venv .venv`、`.venv/bin/python -m pip install -e .` 准备环境，再于项目目录运行 `.venv/bin/python -m csvhub.launch --action start`；重启与停止分别使用 `--action restart`、`--action stop`。没有桌面浏览器的服务器从客户端访问即可。

API 默认监听：`0.0.0.0:8000`。本机访问 `http://127.0.0.1:8000`，其他电脑访问 `http://部署服务器实际IP:8000`；交互文档为同一地址下的 `/docs`。`0.0.0.0` 是监听配置，不是客户端访问地址。

前端首页：`http://127.0.0.1:8000/`，首先显示独立登录页，使用管理员创建的用户名和密码登录。首次升级的管理员可展开「管理员令牌登录」，输入 `data/api-token.txt` 中的原令牌。
管理员页面包含概览、数据集管理、文件导入、任务监控、数据提取、数据查询和系统设置；普通用户只显示概览、提取和查询。令牌仅保存在当前浏览器会话中，退出连接会清除。
不需要安装 Node 或单独启动前端开发服务器，静态页面由同一个后端提供。
完整页面操作说明与前端验证记录见 [FRONTEND.md](FRONTEND.md)。

首次运行自动生成 `data/api-token.txt`。受保护接口需要 `Authorization: Bearer <令牌>`；文档中可用 Header 输入令牌。`/health` 和文档不要求令牌。**必须启动导入执行器，否则任务保持排队。**

可以设置 `CSVHUB_DATA_DIR` 改变存储目录，设置 `CSVHUB_API_TOKEN` 使用自己的随机令牌。两个进程使用相同设置。不要把令牌加入版本控制。

API 和执行器不依赖对方启动顺序；任务由执行器持久化轮询。默认监听所有 IPv4 网卡；需要仅本机使用时，设置 `CSVHUB_HOST=127.0.0.1`。外部部署可由反向代理提供 HTTPS，继续使用现有账号与服务端权限规则。

## 不同服务器与虚拟机访问

默认后端配置使用 `0.0.0.0:8000`，统一的三个入口均读取项目 `.env` 配置，无需随着服务器 IP 或网卡地址变化修改监听配置。系统或当前会话明确设置的环境变量优先于 `.env`；如果之前固定了某个 IP，应删除该覆盖项或改为 `0.0.0.0`。修改配置后使用 `restart.cmd`；修改数据目录前先使用 `stop.cmd`，以便按旧目录停止服务。

IP 变化后，服务仍监听新地址，但客户端网址需要改为新的实际 IP。当前主机的 VMnet8 地址为 `192.168.81.1` 时，NAT 虚拟机访问 `http://192.168.81.1:8000/`；在其他服务器使用该服务器可到达的实际地址。启动检查与本机浏览器仍使用 `127.0.0.1`，不会尝试访问 `0.0.0.0`。端口可通过 `CSVHUB_PORT` 调整，默认 8000。

部署机器需要安装 Python 3.12+ 和项目依赖，并允许预期客户端访问相应 TCP 端口。若服务器能打开首页而客户端不能，请核对访问地址、客户端到服务器的网络连接及防火墙规则。本次更新不会修改操作系统防火墙。

普通 IP 的 HTTP 页面也可进行分块上传校验和创建提取请求；缺少浏览器原生加密摘要或 UUID 方法时，分别复用现有 SHA-256 实现及安全随机字节生成 UUID，保留原有校验和请求去重机制。

## 首次使用

用库存合成示例 CSV：

```csv
record_key,label,event_date,quantity
000001,Widget A,2026-10-09,7
000002,"Widget, B",20261010,3
```

1. `POST /api/v1/datasets` 建立字段定义：

```json
{
  "name": "库存示例",
  "columns": [
    {"name": "key", "source": "record_key", "kind": "text", "indexed": true},
    {"name": "label", "source": "label", "kind": "text", "indexed": true},
    {"name": "date", "source": "event_date", "kind": "date", "indexed": true},
    {"name": "quantity", "source": "quantity", "kind": "integer", "indexed": true}
  ]
}
```

2. `POST /api/v1/uploads` 提供显示文件名、字节数和整文件 SHA256，取得上传 ID。
3. `PUT /api/v1/uploads/{id}/chunks?offset=0` 发送原始二进制请求体；带 `X-Chunk-SHA256`。按返回的 `received` 继续上传。不是 multipart 请求。
4. `POST /api/v1/uploads/{id}/complete` 完成校验。
5. `GET /api/v1/uploads/{id}/preview?encoding=utf-8-sig` 预览列结构。
6. `POST /api/v1/datasets/{id}/imports`，请求 `{"upload_id":"...","encoding":"utf-8-sig","on_error":"fail"}`。
7. `GET /api/v1/jobs/{id}` 轮询至 `completed`。写入完成后还需建索引、校验及预热。
8. `POST /api/v1/datasets/{id}/query` 查询：

```json
{"filters":[{"field":"key","op":"eq","value":"000001"}],"limit":50}
```

返回 `version`、`rows`、`next_cursor`、`cache_hit`。下一页保留相同过滤条件并传入 `cursor`。`explain:true` 返回执行计划，不使用结果缓存。

查询按**首个过滤字段、来源记录号**升序排列；无过滤时按来源记录号排列。所有条件都是 AND。日期支持 YYYY-MM-DD / YYYYMMDD，统一存储为 YYYY-MM-DD。编号务必映射为 text，integer 会去掉前导零。

## 数据与恢复语义

0.3.6 新增简洁独立登录页。站点首页及 `/login` 只显示登录表单，验证成功后跳转到 `/workspace#overview`。工作台在验证会话后才生成后台界面；退出登录或会话过期时返回登录页。管理员令牌登录入口默认折叠，原有账号、密码及服务端权限规则继续生效。

0.3.5 的普通用户概览显示“累计已标注”“今日提取记录”“今日已标注”；管理员概览新增“用户工作统计”，逐账号显示历史提取、历史标注、今日提取、今日标注，包括没有记录或已停用的账号。统计单位均为记录条数，用户统计接口仅管理员可访问。

“今日”以服务器操作系统的本地日期为准，范围为当天零点（含）至次日零点（不含）；数据库仍以 UTC 保存系统时间戳。提取按批次创建时间计数，标注按记录切换为已标注的时间计数，修改备注或重复保存不会计入新的标注。取消标注会从已标注数中扣除，再次标注按新的时间计数。历史标注是当前仍为已标注的记录总数；数据集删除后其提取与标注记录不再参与统计。

旧版本没有单独保存标注时间，首次升级时以已有的最后更新时间初始化标注时间，因此旧记录的今日归属是近似值；升级后的标注与备注时间分开保存。更新完成后需重启服务，浏览器重新加载页面。

每次导入生成 `data/versions/{job_id}.sqlite`，只保留映射的业务列；CSV 原件存储于 `data/uploads`。元数据独立存于 `data/catalog.sqlite`。业务行号是 CSV 数据记录序号，字段内换行不增加记录序号。

执行器每批最多 5000 条记录或约 8MiB 输入内容；较大的单条记录最多 4MiB，禁止整文件载入内存。SQLite 页面缓存预算 32MiB/连接，查询并发最多 4 个，结果缓存预算 128MiB，另有 Python 对象、响应和操作系统缓存开销。缓存预算是包含保守对象开销的估算，并不是操作系统硬性内存上限。

导入数据库使用 WAL + synchronous=FULL；索引临时数据存于磁盘。发布前完成 WAL checkpoint、转回 DELETE 模式并关闭写连接；元数据库在一个事务中更新当前版本指针和任务完成状态。旧版本文件保留，正在执行的查询始终绑定开始时的版本。旧游标在版本切换后明确失效。

CSV 解析恢复采用**从头解析、跳过已提交记录**，不把任意字节偏移当成 CSV 边界。恢复无需重复插入，代价是重新扫描已处理内容。`bytes_read` 是带读取缓冲的近似字节进度，不是可 seek 的恢复位置。批次之外的记录在暂停或失败时不会成为已提交记录。

上传每块先写入临时文件，再持锁追加、fsync，然后提交上传偏移。进程在提交前崩溃留下的多余字节会在下次上传中裁掉。整文件完成校验可重复调用；校验失败需新建上传。长期闲置的临时块或过期版本目前不会自动清理。

标准模式下，`on_error=skip` 跳过列数或字段类型不符合要求的记录，CSV 结构损坏仍会停止。对于确定一行一条记录、字段内没有换行的 CSV，可设置 `row_mode=single_line` 和 `on_error=skip`：每行独立解析，引号格式错误也会整行拒绝，然后继续下一行。表头错误、编码失败和超大记录仍会停止。失败/取消后可以重新创建导入任务；暂停任务恢复原任务。任务状态和错误摘要不保存源单元格内容。

0.2.1 会为新的 CSV 解析错误保存固定错误类型、来源记录序号和文件行范围，任务详情会分别说明已跳过的记录与导致停止的错误。旧任务只保存 `Error` 时无法补回详细信息；拒绝条数不是结构错误的数量。说明见 [导入错误处理](IMPORT-ERRORS.md)。

0.2.2 新增「CSV 记录格式 → 一行一条记录（逐行容错）」选项，以及失败任务的「逐行容错重试」按钮。重试复用已上传文件，新建任务并保留旧任务历史。XLS / XLSX 不使用逐行模式。

## 容量与功能边界

管理员可以在“数据集管理”和“导入任务”中删除记录，点击后会显示删除范围并再次确认。仅已完成、失败、已取消的任务可删除；删除成功任务保留已发布数据，同时清理其独占的原始上传文件。删除数据集会清理全部数据库版本、任务、提取批次、标注、备注及缓存，并清理独占的原始上传文件。进行中或暂停的导入需先取消，其他任务或数据集共用的上传文件会保留。

“原始上传文件”指 `data/uploads` 中由系统保存的 CSV / XLS / XLSX 副本，浏览器选择文件时所在的原目录不在删除范围内。文件清理先暂存再提交，目录事务失败时会恢复；崩溃恢复和暂时被占用的文件会在服务启动或后台重试中继续处理。尚未完成的清理会在页面提示。

- 没有 300MB 或 2000 万行硬编码上限；仍受配置、磁盘、SQLite 和文件系统限制。
- 一次全量导入完成后才能查询该版本；同一数据集同时只允许一个活动或暂停任务。
- 一个数据目录只运行一个执行器；操作系统文件锁会阻止第二个执行器。
- 前缀为区分大小写的 Unicode 文本前缀；首版不支持任意子串、模糊匹配或全文搜索。
- 必须为过滤字段配置索引；最多 64 个字段、16 个索引。组合条件选择第一个条件的索引，因此低选择性条件应放后面。
- 非上传块的请求体最多 128KiB；上传块受独立大小限制，分块传输也会计数检查。
- 索引文本列最多 512 个 Unicode 字符，以限制索引键及游标大小；长描述列应设为 indexed:false。
- 默认每页 50、最多 200 条，响应另有约 8MiB 数据预算；超过预算可能提前分页。单条结果超过响应预算则拒绝交互查询。
- 不提供任意 SQL、服务器任意路径导入、全量内存缓存、导出、自动去重或记录更新接口。
- 令牌只有管理员身份，缓存权限范围为 admin；增加多用户时必须同步扩展缓存权限键。
- 旧版本、源 CSV、索引临时文件需要额外磁盘空间；上传前检查空间不等于为并发上传预留配额。

## 可配置项

安装器首次从 `.env.example` 生成 `.env`，后续不覆盖。配置是普通 UTF-8 文本，支持注释和带引号的路径，不执行脚本或展开变量；相对目录以项目根目录为基准。API、导入执行器与三个服务脚本使用同一配置。可直接修改 `.env`，无需激活虚拟环境或手工设置全局环境变量。已有系统环境变量仍拥有最高优先级。

| 环境变量 | 默认值 |
|---|---|
| CSVHUB_DATA_DIR | data |
| CSVHUB_API_TOKEN | 首次运行自动生成并持久化 |
| CSVHUB_HOST | 0.0.0.0 |
| CSVHUB_PORT | 8000 |
| CSVHUB_BATCH_ROWS | 5000 |
| CSVHUB_BATCH_BYTES | 8388608 |
| CSVHUB_CACHE_BYTES | 134217728 |
| CSVHUB_SQLITE_TEMP_DIR | 不设置；仅限制环境下为单独执行器指定排序临时目录 |

其他限额在 `csvhub/config.py` 的 Settings 中配置。API 与执行器使用同一项目版本和相同字段定义。首次上线需根据实测确认磁盘预算及响应时间。
